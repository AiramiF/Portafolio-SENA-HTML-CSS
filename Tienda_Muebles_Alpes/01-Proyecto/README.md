# 01 - Proyecto: Muebles los Alpes

Esta carpeta contiene la definición a alto nivel del proyecto de comercio electrónico para "Muebles los Alpes". Aquí se explica de qué se trata el sistema, a quién va dirigido y hasta dónde llega.

---

## Objetivo

Establecer las bases fundamentales del portal web de ventas para que cualquier miembro del equipo entienda rápidamente la meta final y los límites del trabajo técnico utilizando HTML, CSS, JavaScript puro y Supabase.

---

## Contenido

- **[Visión](Vision.md):** El propósito del portal web a largo plazo y qué problema de cobertura de ventas resuelve.
- **[Alcance](Alcance.md):** Qué está incluido (ej. carrito de compras, administración) y qué NO está incluido (ej. frameworks, CI/CD, pasarelas de pago reales).

### Orden recomendado de lectura

1. [Visión](Vision.md) (para entender el 'por qué').
2. [Alcance](Alcance.md) (para entender el 'qué').
