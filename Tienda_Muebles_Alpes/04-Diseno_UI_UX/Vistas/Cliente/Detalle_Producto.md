# Vista de Detalle del Producto

Muestra la ficha técnica completa y detallada de un mueble específico seleccionado desde el catálogo.

## Esquema Visual
```text
+-------------------------------------------------------------+
|  < Volver al Catálogo (LNK-001)                             |
+-------------------------------------------------------------+
|                                                             |
|   +-----------------------+   Mesa Ovalada Estilo Griego    |
|   |                       |   Referencia: MESONAT001        |
|   |                       |   Tipo: Interior                |
|   | Foto Grande (IMG-001) |   Material: Madera              |
|   |                       |   Dimensiones: 140x40x55 cm     |
|   |                       |   Color: Natural                |
|   |                       |   Peso: 30 kg                   |
|   +-----------------------+                                 |
|                                                             |
|   Precio: $140.000 COP        Descripción:                  |
|   Disponibles: 2 u.           Mesa ovalada con un elegante  |
|                               diseño de estilo griego.      |
|                                                             |
|   [ Agregar al Carrito (BTN-001) ]                           |
|                                                             |
+-------------------------------------------------------------+
```

## Listado de Subelementos
| Código | Nombre | Propósito |
|---|---|---|
| `LNK-001` | Enlace Volver | Retorna a la vista del catálogo principal. |
| `IMG-001` | Imagen del Producto | Renderiza la fotografía alojada en Cloudinary. |
| `BTN-001` | Botón Agregar | Incrementa en uno la cantidad de este producto en el carrito de compras. |
