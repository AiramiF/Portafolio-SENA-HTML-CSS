# Vista: Error 404 - Página no encontrada

Diseño de la vista que se mostrará cuando el usuario intente acceder a una ruta (URL) que no existe dentro de la aplicación.

---

## Objetivo

Prevenir que el usuario se quede en una pantalla en blanco o reciba un error genérico del servidor, ofreciéndole en su lugar una salida amigable y un camino claro de regreso al flujo principal (el catálogo).

---

## Contenido

### Esquema Visual (Wireframe)

```text
+---------------------------------------------------+
|                   Header (HD-001)                 |
+---------------------------------------------------+
|                                                   |
|                [ Icono de Lupa Rota ]             |
|                                                   |
|           ¡Ups! Parece que te has perdido         |
|      La página que buscas no existe o ha sido     |
|                      movida.                      |
|                                                   |
|          [ Botón Primario: Volver al Inicio ]     |
|                                                   |
+---------------------------------------------------+
|                   Footer (FT-001)                 |
+---------------------------------------------------+
```

### Elementos de UI Utilizados
- `HD-001` (Header)
- `FT-001` (Footer)
- `BTN-001` (Botón Primario - Enlace al Catálogo / `index.html`)

### Lógica (IPO)
- **Entrada:** URL inválida detectada por el enrutador Vanilla JS o acceso directo.
- **Proceso:** Renderiza esta vista en el contenedor principal.
- **Salida:** Botón de redirección.
