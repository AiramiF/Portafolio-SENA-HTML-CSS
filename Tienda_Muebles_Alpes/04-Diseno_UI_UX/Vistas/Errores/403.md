# Vista: Error 403 - Acceso Denegado

Diseño de la vista protectora que se mostrará cuando un usuario intente acceder a un recurso para el cual no tiene los permisos suficientes (Ej. Un Cliente intentando entrar al panel del Administrador).

---

## Objetivo

Informar de manera clara y segura al usuario que no tiene autorización para ver el contenido solicitado, bloqueando la navegación indebida sin revelar información sensible y ofreciendo un punto de retorno seguro.

---

## Contenido

### Esquema Visual (Wireframe)

```text
+---------------------------------------------------+
|                   Header (HD-001)                 |
+---------------------------------------------------+
|                                                   |
|                [ Icono de Candado Cerrado ]       |
|                                                   |
|                   Acceso Denegado                 |
|      No tienes los permisos necesarios para       |
|                 acceder a esta área.              |
|                                                   |
|          [ Botón Primario: Ir al Catálogo ]       |
|                                                   |
+---------------------------------------------------+
|                   Footer (FT-001)                 |
+---------------------------------------------------+
```

### Elementos de UI Utilizados
- `HD-001` (Header)
- `FT-001` (Footer)
- `BTN-001` (Botón Primario - Enlace al inicio de sesión o catálogo).

### Lógica (IPO)
- **Entrada:** Verificación de rol en el objeto de sesión (Supabase Auth) arroja 'Cliente' en una ruta protegida.
- **Proceso:** El guardia de ruta (router.js) aborta la carga de la vista administrativa y renderiza este componente.
- **Salida:** Mensaje disuasivo y botón de escape.
