# 02 - Requisitos: Muebles los Alpes

Esta carpeta centraliza las expectativas del portal de ventas. Define exactamente qué debe hacer la aplicación web, el carrito de compras, los módulos de administración y bajo qué condiciones tecnológicas debe operar.

---

## Objetivo

Tener una fuente única de verdad sobre las funcionalidades del sistema para que diseño, desarrollo y pruebas trabajen alineados, respetando el uso exclusivo de Vanilla JS/HTML/CSS y Supabase.

---

## Contenido

- **[Requisitos Funcionales](Funcionales.md):** Qué debe *hacer* el sistema (procesos de compra, gestión de inventario, reportes).
- **[Requisitos No Funcionales](No_Funcionales.md):** Cómo debe *comportarse* el sistema (tecnologías puras, infraestructura en Vercel, Supabase).
- **[Flujos de Negocio](Flujos_Negocio.md):** Los pasos de negocio y actores involucrados en cada proceso principal (`FL-xxx`).

### Orden recomendado de lectura

1. [Requisitos Funcionales](Funcionales.md)
2. [Requisitos No Funcionales](No_Funcionales.md)
3. [Flujos de Negocio](Flujos_Negocio.md)
