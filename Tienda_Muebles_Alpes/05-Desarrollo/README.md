# 05 - Desarrollo: Muebles los Alpes

Esta carpeta dicta las reglas de juego para escribir código en el portal web. Cómo configurar la máquina local, qué convenciones de Vanilla JS / CSS usar y cómo trabajar con Git.

---

## Objetivo

Mantener un estándar de código alto, asegurando que todos los desarrolladores escriban HTML/CSS/JS de forma coherente y rastreable hacia los requisitos.

---

## Contenido

- **[Convenciones de Código](Convenciones_Codigo.md):** Reglas de trazabilidad (RF-xxx) y buenas prácticas en Vanilla Web.
- **[Flujo Git](Flujo_Git.md):** Cómo nombrar ramas y commits.

### Orden recomendado de lectura

1. [Convenciones de Código](Convenciones_Codigo.md) (vital antes de escribir la primera línea).
2. [Flujo Git](Flujo_Git.md) (antes de hacer el primer commit).
